# 主动ETF研究册

**[打开网页浏览](https://wutop1an.github.io/active-etf-research/)**

首批18只主动ETF的独立资料页：可搜索总目录、左侧基金导航、逐只查看购买渠道与费用、投资方法、基金经理关联旧基金成绩及同期比较基准。

## 信息时点与读法

- 资料整理：2026-10-21 16:57，北京时间。本项目是固定快照，募集、成立、上市进度不会自动更新。
- 旧基金收益主要截至2026-06-30；各表分别注明期间。超额为同期间基金收益减去比较基准收益，单位为百分点。
- 关联旧基金成绩不是新ETF业绩，也不一定等于现任经理独立管理期间的成绩；共管与接任时间在页面中说明。
- 新ETF尚未成立时，没有实际持仓和历史业绩。旧基金持仓用于了解历史风格，不能当作新产品预定持股。
- 每只页面附来源链接，并标出尚未核实或未补齐的内容。购买渠道及发售安排请结合之后的正式公告。

## 本地浏览与部署

下载项目后直接打开 `index.html`，或在本目录执行 `python -m http.server 8000 --bind 127.0.0.1`，再访问本机8000端口。

本项目使用纯HTML、CSS和JavaScript，无需安装依赖或构建。GitHub Pages从 `main` 分支根目录发布，更新文件并推送后即可重新部署。

网页无登录、后台服务或账户接口。本项目只含独立静态资料，不包含个人持仓或本地投资工作区历史。

## 访问统计

自2026-10-21启用，页脚显示项目浏览次数、估算访客数与本页浏览次数。服务为[soxft/busuanzi的公共实例](https://busuanzi.9420.ltd/)，[接口说明](https://busuanzi.apifox.cn/api-203999144)。无付费账户、后端凭据或API密钥；本项目自行调用JSON接口，不加载远程可执行脚本。

- 项目合计使用`https://wutop1an.github.io/active-etf-research/`对应的`page_pv/page_uv`；每个页面另用规范化地址。首页`/`与`/index.html`统一为同一页面。忽略服务返回的域名级`site_*`，避免混入其他项目。
- 每次可见页面加载最多提交一次项目计数、一次本页计数。刷新读数只用GET；计数失败不自动重发POST，以免服务已经记账却重复增加。
- UV是去重估算，不是精确自然人数。服务端开源实现由IP与User-Agent的哈希产生标识，浏览器保存返回的统计标识以便连续去重；网络、浏览器变化和拦截均可能影响读数。包括维护者正常访问，不回填启用前的访问。
- 发送公开页面地址时去除查询参数及锚点，并不发送当前网页的HTTP Referer或浏览器Cookie。统计服务仍会收到网络IP和浏览器User-Agent，不宣称完全匿名。
- 页脚可关闭统计，偏好保存在当前浏览器。尊重DNT和Global Privacy Control；关闭时不向计数服务请求读数。本地与其他域名预览不计数。
- 公益实例没有SLA或数据永久保留保证。服务故障显示“暂不可用”，阅读和GitHub入口不受影响；不把失败显示成零。
- 验收可使用`?stats=read`仅查询而不增加统计；这个模式在页脚明确标示。勿用重复访问人为制造热度。
